## Как используется в ASCII ART STUDIO

`DejaVuSansMono.ttf` вшит в бинарник (`src-tauri/assets/DejaVuSansMono.ttf`,
`include_bytes!`) и используется для растеризации ASCII-символов при экспорте
в PNG/GIF/MP4 и для кадров виртуальной камеры.
