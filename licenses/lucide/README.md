# Lucide Icons

- **Проект:** Lucide — набор SVG-иконок (форк Feather Icons)
- **Авторы:** Lucide Icons and Contributors
- **Сайт:** https://lucide.dev/
- **Лицензия:** ISC (см. `LICENSE` рядом)

## Как используется в ASCII ART STUDIO

Пакет `lucide-react` — иконки интерфейса (кнопки, панели). Иконки
компилируются в JS-бандл приложения при сборке.
